## Your K Calculations
- `K = 51`
- `K mod 3 = 0`: Extra feature — save all labels and variables with their addresses in `symbols.txt`.
- `K mod 4 = 3`: Box width = `16 × ((3) + 1) = 64 pixels` = 4 words.
- Starting row = `51`.
- Height = `20` rows (rows `51` through `70`, inclusive).
- Starting screen address = `SCREEN + 32 × 51 = 16384 + 1632 = 18016`.
- After writing 4 words, the address pointer has advanced 3 words; add 29 more words to reach the next row (32 words total).

## How to Run the Assembler
To assemble `Box.asm` into `Box.hack`:
```bash
python assembler.py Box.asm
```
The assembler also writes `symbols.txt` because `K mod 3 = 0`.

To test the other programs:
```bash
python assembler.py Add.asm
python assembler.py Max.asm
python assembler.py Rect.asm
python assembler.py Pong.asm
```

## How to Run in CPU Emulator
1. Open the Nand to Tetris CPU Emulator.
2. Load Program: select `Box.hack`.
3. Set Animation to `Program & Data` or `No display` (Fast).
4. Click `Run`.
5. Focus the emulator and hold down any keyboard key — a solid black box should appear at Row 51.
6. Release the key — the box should clear back to white.
